# QUO VADIS - Séances État-major

Décision MOA du 08.10.2026 : une Séance État-major utilise le Stat.Com
canonique `EMSEA`. `EMSEA` est distinct de `EXEC` ; aucune succession ni
conversion entre ces codes n'est autorisée.

Ces séances sont soldées au forfait, sans décompte d'heures. Le code `EMSEA`
est valide à partir du 01.01.2026 pour les séances État-major. Les autres
Stat.Com restent soumis à la validation canonique habituelle.

Référentiel exécutable : `netlify/lib/_scope-statcom-referential.js`.
Matérialisation SQL requise avant mise en production :
`database/migrations/20261008_scope_qv_statcom_emsea.sql`.
